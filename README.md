# Payment Operations Analytics Dashboard

## Project Overview
This project analyzes payment transaction data using Power BI to monitor transaction success rates, failure reasons, merchant performance, city-wise transaction volume, and revenue trends.


## Business Objective
The objective is to help a fintech/payment company track key operational metrics and identify transaction failure patterns to improve payment success rate and merchant experience.

## Tools Used
- Power BI
- DAX
- CSV Dataset
- Data Visualization

## Key KPIs
- Total Transactions
- Total Revenue
- Success Rate
- Failure Transactions
- Average Transaction Value

## Dashboard Features
- Transactions by Payment Method
- Success vs Failed Transactions
- Transaction Failure Reasons
- Revenue by Merchant Category
- Monthly Revenue Trend
- City-wise Transaction Volume
- Top Merchants by Revenue

## Key Insights
- UPI had the highest transaction volume.
- Overall success rate was above 92%.
- Transaction failures were mainly caused by bank/server and payment gateway-related issues.
- E-commerce and travel merchant categories contributed the highest revenue.
- City-wise transaction distribution showed strong activity across major Indian cities.

## Business Recommendations
- Monitor failure reasons regularly to reduce payment drop-offs.
- Improve gateway response handling for high-failure payment methods.
- Focus merchant support on high-volume and high-revenue categories.
- Track city-wise performance to identify regional transaction trends.
